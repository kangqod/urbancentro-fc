# 선수 명단 시트 사용설명서

앱은 Google Sheets에 게시된 CSV를 페이지를 열 때마다 읽어 선수 명단으로 씁니다. 명단을 고치면 재배포 없이 다음 새로고침부터 반영됩니다.
템플릿 파일: [`roster-template.csv`](./roster-template.csv)

## 1. 시트 만들기

1. Google Sheets에서 새 스프레드시트 생성
2. **파일 → 가져오기 → 업로드** 에서 `roster-template.csv` 선택 → "현재 시트 바꾸기"
3. 예시 행(홍길동 등 4명)을 지우고 실제 선수를 입력
4. 아래 **2. 열 규칙**과 **3. 유형 검증** 을 반드시 적용
5. 앱이 읽을 CSV 주소를 만들어 개발자에게 전달합니다. 두 방법 중 하나:
   - **A. 웹에 게시(권장)** — **파일 → 공유 → 웹에 게시** → 첫 드롭다운을 해당 시트로, 두 번째를 **쉼표로 구분된 값(.csv)** 으로 → "변경사항이 있을 때 자동으로 다시 게시" 체크 → 게시. 주소 형태: `https://docs.google.com/spreadsheets/d/e/2PACX-…/pub?gid=…&single=true&output=csv`
     문서 공유를 "제한됨"으로 두어도 동작하고, 선택한 시트만 공개됩니다. 반영은 최대 약 5분.
   - **B. gviz 주소** — 웹에 게시 메뉴를 쓸 수 없을 때(문서 소유자가 편집자의 공유 변경을 막아둔 경우). 문서 공유를 **"링크가 있는 모든 사용자(뷰어)"** 로 두고 아래 형태의 주소를 씁니다. `{문서ID}`는 주소창의 `/d/` 뒤, `{gid}`는 `gid=` 뒤 숫자입니다.
     `https://docs.google.com/spreadsheets/d/{문서ID}/gviz/tq?tqx=out:csv&gid={gid}`
     수정이 즉시 반영되지만, **같은 문서의 모든 탭이 링크만 알면 열립니다.** 연락처 같은 개인정보 탭이 있는 문서에서는 쓰지 말고, 명단 탭을 새 문서로 분리하세요.

## 2. 열 규칙

헤더 7개는 이름을 바꾸거나 지우면 안 됩니다(순서는 바꿔도 됨). 행은 자유롭게 추가·삭제·수정할 수 있습니다. `비고`처럼 **열을 더 추가하는 것은 허용**됩니다 — 앱은 아는 헤더만 읽고 나머지는 무시합니다(단, 게시 CSV에는 포함되니 민감한 메모는 피하세요).

| 열       | 규칙                                                                                                                                                 | 예시                  |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| 이름     | 필수. **1~6글자**. **동명이인은 넣을 수 없습니다** — 이름이 같으면 `B`, `C` 접미사를 붙이세요. 빈 행은 무시됩니다                                    | `홍길동`, `홍길동B`   |
| 출생년도 | **1950~2100** 사이 4자리. 2자리로 쓰면 자동 보정되지만(`95` → 1995) 4자리를 권장                                                                     | `1990`                |
| 등번호   | 정수. **등번호가 없으면 `0`** (앱에서 "없음"으로 표시)                                                                                               | `10`, `0`             |
| 티어     | `에이스` / `상급` / `중급` / `초급` 중 하나. **정말 프로급이 아니라면 최상위는 `상급`으로** 처리하는 걸 권장. 오타는 `중급`으로 들어갑니다           | `상급`                |
| 강점     | 자유 텍스트 한 줄. 비워도 됨                                                                                                                         | `골 결정력`           |
| 특성     | **`/`로 구분**하면 여러 개를 쓸 수 있습니다. 비워도 됨                                                                                               | `빠른 침투/양발 슈팅` |
| 프리미엄 | **애니메이션(강조 이펙트)이 적용되는 선수**. 해당 선수에만 `1`, 나머지는 빈칸. (프리미엄 선수는 탑독 판정 가중치를 받고 HIGH 컨디션을 받지 않습니다) | `1`                   |

동명이인 예) `홍길동B` / `2001` / `상급`

## 3. 유형 검증 (데이터 확인) — 반드시 설정

입력 실수를 시트 단계에서 막기 위해 각 열에 **데이터 → 데이터 확인** 규칙을 걸어 두세요. 범위는 2행부터 충분히 아래까지(예: `A2:A200`) 잡습니다.

| 열       | 기준               | 조건                                              | 잘못된 데이터 처리 |
| -------- | ------------------ | ------------------------------------------------- | ------------------ |
| 이름     | 텍스트 → 맞춤 수식 | `=AND(LEN(A2)>=1, LEN(A2)<=6, COUNTIF(A:A,A2)=1)` | 입력 거부          |
| 출생년도 | 숫자 → 사이        | `1950` ~ `2100`                                   | 입력 거부          |
| 등번호   | 숫자 → 이상        | `0`                                               | 입력 거부          |
| 티어     | 목록               | `에이스,상급,중급,초급` (드롭다운 표시 체크)      | 입력 거부          |
| 프리미엄 | 목록               | `1` (드롭다운 표시 체크)                          | 입력 거부          |

- 이름 수식의 `COUNTIF(A:A,A2)=1`이 동명이인을 막습니다. 같은 이름을 넣으려면 접미사를 붙여 다른 이름으로 만드세요.
- 강점·특성은 자유 텍스트라 검증을 걸지 않습니다.

## 4. 반영과 장애

- 반영: 시트 저장 → 게시 복사본 갱신(최대 약 5분) → 사용자가 앱을 **새로고침**하면 반영. 열어둔 탭은 갱신되지 않습니다.
- 시트를 못 읽으면(네트워크·Google 장애·헤더 훼손) 앱은 그 기기에 **마지막으로 성공한 명단**을 쓰고 "…저장된 명단을 사용합니다" 안내를 띄웁니다. 그것도 없으면 에러 화면에서 다시 시도만 가능합니다.
- 헤더를 잘못 건드려 앱이 에러 화면을 보이면, 헤더 7개를 템플릿과 똑같이 되돌리세요.

## 5. 앱 코드에 남아 있는 것 (시트로 바뀌지 않음)

- `지원 1`, `지원 2` 대체 슬롯
- 같은 팀에 두지 않는 선수 쌍, OCR 오인식 보정 이름
- 위 항목을 바꾸려면 개발자에게 요청하세요.
